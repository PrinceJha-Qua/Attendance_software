# Changelog

## 1.0.0-rc1 (release candidate)
Everything in the v1 scope (`docs/V1_SCOPE_AND_PHASES.md`).
- P1 Foundation: auth, roles, uniform errors, API contract.
- P2 Courses, roster CSV import, enrollment and confirmation, encrypted reference photos.
- P3 Sessions, signed rotating QR tokens, projection screen.
- P4 Student check-in: QR scan, per-student replay guard, idempotent results.
- P5 Face layer: on-device embeddings, colour-flash liveness, trust scoring, collisions.
- P6 Ultrasonic beacon: chirp-keyed bursts, offline simulation, soft scoring.
- P7 Live console: WebSocket feed, Attention Panel, spot-checks, close, CSV export.
- P8 Dashboards: exact attendance calculator, disputes, professor reports.
- P9 Hardening: rate limits, headers, structured logs, retention, prod guards, deploy stack, backups.
- P10 Freeze: repository cleanup, documentation, field protocol.

Not yet field-tested; see `docs/KNOWN_ISSUES.md`.
