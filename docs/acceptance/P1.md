# Phase 1 acceptance: Foundation and contracts
Scope: `docs/V1_SCOPE_AND_PHASES.md` P1. Run from `backend/`: `uv sync`, `uv run python scripts/seed.py`, `uv run uvicorn app.main:app`. Base path `/api/v1`. Dev password for all seeded users: `gatekeeper-dev` (prof@example.edu, student01..30@example.edu, roll numbers R001..R030).

## What is real in P1
`POST /auth/login`, `POST /auth/refresh`, `POST /auth/logout`, `GET /me`, `GET /time`, `GET /healthz`, `GET /readyz`.
Everything else in V1 section 4 exists as a **stub** returning `501 NOT_IMPLEMENTED` with the correct auth rule.

## Test cases for AGY
**Contract**
1. `docs/openapi.json` (regenerate with `uv run python scripts/export_openapi.py`) contains every method+path listed in V1 section 4 (47 operations incl. auth/ops) and no extras. WebSocket `/api/v1/ws/sessions/{id}` exists but closes with code 1013.
2. For each stub: no token -> 401; wrong role -> 403; right role -> 501. Role map is in `app/routers/stubs.py` (S = student, P = professor).
3. Error body shape on every 4xx/5xx: `{"error":{"code","message","request_id"}}`; validation failures are 422 `VALIDATION_ERROR`.

**Auth**
4. Login works with email or roll number; wrong password and unknown identifier both return 401 `INVALID_CREDENTIALS` with the same body.
5. Access token works on `/me`; refresh token does not (401). Refresh token works on `/auth/refresh`; access token does not (401).
6. Expired token -> 401 (set `GK_ACCESS_TTL_S=1`). Tampered signature -> 401. `alg=none` token -> 401.
7. `/me` returns role matching the account; `/time` returns server epoch ms within 2 s of the test clock.
8. `GET /readyz` -> 200 with DB up.
9. With `GK_ENV=prod` and no `GK_SECRET_KEY` the app refuses to start.

**Data**
10. After seed: 1 professor, 30 students, 1 course, 30 roster rows. Seed is idempotent (second run prints "already seeded").
11. Password hashes are argon2 (never plaintext in the DB).

## Out of scope (do not test yet)
Any business logic, QR tokens over HTTP, enrollment, check-in, WS events. Token module unit tests already exist in `backend/tests/test_tokens.py`; AGY may replace or extend them.
